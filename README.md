# Parcels-Data-Cleaning-Automation-Pipeline
this autoamte data cleaning when sourced from metabase weekly before being fed into visualisation models in excel and power bi

**Project Description**

This project focuses on automating the data cleaning and preparation pipeline for parcel-level data extracted weekly from Metabase. The dataset plays a critical role in supporting operational decision-making, particularly during peak farmer engagement periods where timely and reliable insights are essential.

The objective is to streamline and standardize the data processing workflow, reducing manual intervention, minimizing errors, and ensuring consistency across reporting cycles. The cleaned and structured data is then seamlessly integrated into visualization models built in Excel and Power BI, enabling efficient monitoring, analysis, and decision support.
